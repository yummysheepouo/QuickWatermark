## 🖼️ QuickWatermark 是什麼？

QuickWatermark 是一款簡單但功能強大的工具，可為圖片、GIF和影片添加文字或圖像水印。  
它提供直覺式的 Streamlit 網頁介面，支援自訂字體，並可在 Windows、macOS 和 Linux 上運行。

<img src="/docs/example-zh.png" alt="QuickWatermark Screenshot" width="600" height="500" />



## ✨ 功能特色

- 為 PNG、JPG、GIF、MP4、MOV 和 WEBM 檔案添加文字或圖像水印  
- 自訂水印位置、大小、顏色、透明度、旋轉角度和平鋪方式  
- 支援自訂字體（TTF/OTF）  
- 即時預覽並輕鬆下載加上水印的檔案  
- 跨平台支援



## 🚀 快速開始

1. **下載此專案：**
   在版本發佈頁面中下載你偏好的語言與平台版本
   [**🔗 Window - 英文**](https://github.com/yummysheepouo/QuickWatermark/releases/download/beta/English-window.zip)
   [**🔗 Window - 中文**](https://github.com/yummysheepouo/QuickWatermark/releases/download/beta/Chinese-window.zip)
   [**🔗 MacOS - 英文**](https://github.com/yummysheepouo/QuickWatermark/releases/download/beta/English-macOS.zip)
   [**🔗 MacOS - 中文**](https://github.com/yummysheepouo/QuickWatermark/releases/download/beta/Chinese-macOS.zip)
   或複製此專案
   ```bash
   git clone https://github.com/yummysheepouo/QuickWatermark.git
   cd QuickWatermark
   ```
2. **安裝依賴套件：**
   ```
   pip install -r requirements.txt
   ```
   或
   ```
   pip install streamlit Pillow numpy moviepy==1.0.3
   ```

3. **啟動應用程式：**
   點擊 `start.bat` 或 `start.sh` 執行應用程式
   若無法啟動，可改用以下指令：
   ```
   streamlit run main.py
   ```

4. **打開瀏覽器**開始為你的作品加上你的水印吧！
