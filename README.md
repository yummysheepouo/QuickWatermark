## 🖼️ What is QuickWatermark?
QuickWatermark is a simple and powerful tool for adding text or image watermarks to images, GIFs, and videos.  
It features an intuitive Streamlit web interface, supports custom fonts, and works on Windows, macOS, and Linux.

<img src="/docs/example.png" alt="QuickWatermark Screenshot" width="600" height="500" />


## ✨ Features

- Add text or image watermarks to PNG, JPG, GIF, MP4, MOV, and WEBM files 
- Customize watermark position, size, color, opacity, rotation, and tiling
- Support for custom fonts (TTF/OTF)
- Real-time preview and easy download of watermarked files
- Cross-platform support

## 🚀 Quick Start

1. **Download the files**
   Download your prefered languages and platform in the release<br>
   [**🔗 Window - English**](https://github.com/yummysheepouo/QuickWatermark/releases/download/beta/English-window.zip)<br>
   [**🔗 Window - Chinese**](https://github.com/yummysheepouo/QuickWatermark/releases/download/beta/Chinese-window.zip)<br>
   [**🔗 MacOS - English**](https://github.com/yummysheepouo/QuickWatermark/releases/download/beta/English-macOS.zip)<br>
   [**🔗 MacOS - Chinese**](https://github.com/yummysheepouo/QuickWatermark/releases/download/beta/Chinese-macOS.zip)<br><br>
   Or clone the repository:
   ```
   git clone https://github.com/your-username/QuickWatermark.git
   cd WatermarkCraft
   ```

2. **Install dependencies:**
   ```
   pip install -r requirements.txt
   ```
   Or 
   ```
   pip install streamlit Pillow numpy moviepy==1.0.3
   ```

3. **Run the app:**
  Click the `start.bat` or `start.sh` to run the app
  If not working, run the command instead:
   ```
   streamlit run main.py
   ```

4. **Open your browser** and start watermarking!
