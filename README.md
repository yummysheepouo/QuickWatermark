# QuickWatermark

QuickWatermark is a simple and powerful tool for adding text or image watermarks to images, GIFs, and videos.  
It features an intuitive Streamlit web interface, supports custom fonts, and works on Windows, macOS, and Linux.

## Features

- Add text or image watermarks to PNG, JPG, GIF, MP4, MOV, and WEBM files
- Customize watermark position, size, color, opacity, rotation, and tiling
- Support for custom fonts (TTF/OTF)
- Real-time preview and easy download of watermarked files
- Cross-platform support

## Quick Start

1. **Clone the repository:**
   ```
   git clone https://github.com/your-username/QuickWatermark.git
   cd WatermarkCraft
   ```

2. **Install dependencies:**
   ```
   pip install -r requirements.txt
   ```

3. **Run the app:**
   ```
   streamlit run main.py
   ```

4. **Open your browser** and start watermarking!
